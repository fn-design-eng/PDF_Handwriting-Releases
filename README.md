# PDF手書き — Windows配布版

PDFに手書き・文字・図形・画像/PDFスタンプ等の注釈を追加し、保存・印刷するWindowsアプリです。

[最新の配布版をダウンロード](https://github.com/fn-design-eng/PDF_Handwriting-Releases/releases/latest)

## 使用方法

1. Releasesから最新版のZIPまたは7zを取得します。
2. 書き込み可能なフォルダーへすべて展開します。
3. `PDF手書き-portable/PDF手書き.exe`を起動します。

Windows 10/11 x64とMicrosoft Edge WebView2 Runtimeが必要です。文字注釈や日付スタンプではWindowsのMS ゴシックやMS 明朝などを使います。Windowsのフォントファイルは同梱していません。

EXE、`bin`、`licenses`、利用案内・対応ソースを含むフォルダー一式を保持してください。詳しい使い方と0.7.6からの変更は配布セットの`README.txt`と[0.7.7 Release案内](RELEASE_0.7.7.md)に記載しています。EXEはAuthenticode未署名です。
